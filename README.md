Command-line Interface
======================

Users can interact with the Entity Resolution comparison system via the command line.
This is a suitable use-case when evaluating the system or for first interactions. This
package provides the `matchescu` CLI that is host to a number of sub-commands that allow
peering into the ER system's way of working.

Installation
------------

The `matchescu` CLI is available to install via `pip`. To install the latest version for
the current user, run the following command:

```shell
$ pip install --user matchescu-cli
```
